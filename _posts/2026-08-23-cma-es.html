  • Covariance Matrix Adaptation Evolution Strategy
    • CMA-ES only needs a score for each possible answer, called a candidate. It can work without a gradient, which tells you how the score changes near a point.
    • CMA-ES uses a normal distribution \(\mathcal{N}(m, \sigma^2 C)\) to draw candidates. This puts more candidates near the center. In each round, called a generation, it draws \(\lambda\) candidates and ranks them by score. The best candidates guide the next round.
    • The mean \(m\) is the center. The step size \(\sigma\) sets the overall spread. The matrix \(C\) sets how the search stretches in different directions.

  • Example: the smallest circle containing all points
    • Find the smallest circle that holds six points. Each candidate gives a possible center \((x, y)\). You choose two numbers, so \(n = 2\).
    • Each \(p_i\) is one of the six points. From a given center, find the distance to the farthest point. That distance is both the radius and the score \(f\).
      \[ f(x, y) = \max_i \, \lVert (x, y) - p_i \rVert \]

How it evolves
  • How \(m\) is calculated
    • Without the extra 0.5, both the starting value and rank 3 would be 3. Dividing them gives 1, and \(\ln(1)=0\). The third sample would get zero weight.
    • Use \(\ln\!\left(\frac{\text{starting value}}{\text{rank}}\right)\) to get a log score for each rank. Add up the log scores. Then divide each score by that sum to get its weight.
    • Multiply each of the three centers by its weight. Add the results to get the new center \(m\).

  • How \(C\) and \(\sigma\) change

    The dashed ellipse in Fig. 1 shows where CMA-ES is likely to draw more samples. Changing \(C\) can stretch or turn the ellipse. Changing \(\sigma\) makes the whole ellipse bigger or smaller. Both axes change by the same factor. The next example uses simple numbers to show how \(C\) changes.

    • Learn from the best samples
      Start at \(m_{\text{old}}=(0,0)\) with \(\sigma=1\). From best to third best, the samples are \(s_1=(2,0)\), \(s_2=(0,2)\), and \(s_3=(-2,0)\). Give them weights of \(0.5\), \(0.25\), and \(0.25\). For each sample, draw an arrow from the old center to that sample. Divide its two numbers by \(\sigma\) to get \(d_i\). Here \(\sigma=1\), so the arrow stays the same. \[ \begin{aligned} d_1 &= \frac{s_1 - m_{\text{old}}}{\sigma} = (2,0)-(0,0) = \begin{pmatrix}2\\0\end{pmatrix} \\[0.5em] d_2 &= \frac{s_2 - m_{\text{old}}}{\sigma} = (0,2)-(0,0) = \begin{pmatrix}0\\2\end{pmatrix} \\[0.5em] d_3 &= \frac{s_3 - m_{\text{old}}}{\sigma} = (-2,0)-(0,0) = \begin{pmatrix}-2\\0\end{pmatrix} \end{aligned} \] Write the arrow's numbers as a column and as a row. Multiply the column by the row to get a matrix. For \(d_1\), the top-left number is \(2^2=4\), and the rest are zero. The arrow pointing left, \(d_3\), gives the same matrix. The arrow pointing up, \(d_2\), puts its \(4\) at the bottom right. Fig. 2 multiplies each arrow's length by \(\sqrt{w_i}\). The column and row each get one copy of \(\sqrt{w_i}\). The two square roots multiply to \(w_i\), so the matrix gets the right weight.
      \[ \begin{aligned} S &= 0.5 d_1 d_1^\top + 0.25 d_2 d_2^\top + 0.25 d_3 d_3^\top \\[0.5em] &= \begin{pmatrix}2&0\\0&0\end{pmatrix} + \begin{pmatrix}0&0\\0&1\end{pmatrix} + \begin{pmatrix}1&0\\0&0\end{pmatrix} \\[0.5em] &= \begin{pmatrix}3&0\\0&1\end{pmatrix} \end{aligned} \]

      To decide how much \(S\) should affect \(C\), start with the same three weights \(w_1,w_2,w_3\). Square each weight. Add the squares, then divide 1 by the total. This gives the effective sample count \(\mu_{\text{eff}}\). With equal weights, it would be 3. Here the best sample counts more, so the result is about 2.67.

      \[ \begin{aligned} \mu_{\text{eff}} &= \frac{1}{\vphantom{\rule{0pt}{1.3em}}w_1^2+w_2^2+w_3^2} \\[0.5em] &= \frac{1}{\vphantom{\rule{0pt}{1.3em}}0.5^2+0.25^2+0.25^2} \approx 2.67 \end{aligned} \]

      The formulas below use two numbers. The first is \(n\), the number of values we choose. The second is \(\mu_{\text{eff}}\), the count we just found. The rate \(c_1\) sets how much the record of center moves affects \(C\). The rate \(c_\mu\) sets how much \(S\) affects \(C\).

      \[ \begin{aligned} c_1 &= \frac{2}{\vphantom{\rule{0pt}{1.3em}}(n+1.3)^2+\mu_{\text{eff}}} \\[0.5em] c_\mu &= \min\left( 1-c_1,\, \frac{2(\mu_{\text{eff}}-2+1/\mu_{\text{eff}})} {\vphantom{\rule{0pt}{1.3em}}(n+2)^2+\mu_{\text{eff}}} \right) \end{aligned} \]

      We choose \(x\) and \(y\), so use 2 for \(n\). Use 2.67 for \(\mu_{\text{eff}}\). In the \(c_\mu\) formula, \(\min\) means take the smaller value. Here the fraction gives \(0.11\), which is below the limit \(1-c_1\approx0.85\).

      \[ \begin{aligned} c_1 &= \frac{2}{\vphantom{\rule{0pt}{1.3em}}(2+1.3)^2+2.67} \approx 0.15 \\[0.5em] c_\mu &= \frac{2(2.67-2+1/2.67)}{\vphantom{\rule{0pt}{1.3em}}(2+2)^2+2.67} \approx 0.11 \end{aligned} \]

      Use the rates shown to two decimal places. Save \(0.15\) for the center moves and use \(0.11\) for \(S\). The old spread \(C_{\text{old}}=I\) gets the rest, \(1-0.15-0.11=0.74\).

      \[ C_{\text{samples}} = 0.74 I + 0.11 S = \begin{pmatrix}1.07&0\\0&0.85\end{pmatrix} \]
    • Learn from center moves
      Use the three weights to average the sample positions. The center moves from \((0,0)\) to \((0.5,0.5)\). Dividing this move by \(\sigma=1\) gives the same pair. The vector \(p_c\) keeps a record of the center moves. In this example, start with \((1,1)\) for the old record. Keep half of it and add the latest move. \[ p_{c,\text{new}} = 0.5\begin{pmatrix}1\\1\end{pmatrix} + \begin{pmatrix}0.5\\0.5\end{pmatrix} = \begin{pmatrix}1\\1\end{pmatrix} \] The orange arrow points up and right. Multiply its column by its row to get a matrix of ones. Multiply the matrix by \(0.15\), the rate we found above. Add it to \(C_{\text{samples}}\).
      \[ \begin{aligned} C_{\text{new}} &= C_{\text{samples}} + 0.15 \begin{pmatrix}1&1\\1&1\end{pmatrix} \\ &= \begin{pmatrix}1.22&0.15\\0.15&1\end{pmatrix} \end{aligned} \]
    • Change size (\(\sigma\))

      CMA-ES keeps an arrow for recent center moves. Each round, it keeps part of the old arrow and adds the latest move, scaled to the old sampling spread. Moves in the same direction add up. Moves in opposite directions partly cancel.

      In Fig. 5, the older moves contribute 1.034 units to the right. The latest move adds 1.398 units to the right or left. The combined arrow has length \(L\approx 2.43\) or \(L\approx 0.36\).

      Divide \(L\) by 1.25, the average path length for random moves in 2D. The resulting ratio \(r\) tells us how to change \(\sigma\). When \(r\) is above 1, \(\sigma\) grows. When it is below 1, \(\sigma\) shrinks. At 1 it stays the same. This example uses an update rate of 0.289.

      \[ \begin{aligned} r &= L/1.25 \\[0.5em] \sigma_{\text{new}} &= \sigma_{\text{old}}\,e^{0.289(r-1)} \\[0.5em] L=2.43 &\;\Rightarrow\; \sigma_{\text{new}}\approx 1.31\sigma_{\text{old}} \\ L=0.36 &\;\Rightarrow\; \sigma_{\text{new}}\approx 0.81\sigma_{\text{old}} \end{aligned} \]
