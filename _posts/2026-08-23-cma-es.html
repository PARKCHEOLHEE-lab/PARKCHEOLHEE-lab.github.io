  • Optimizing without a gradient
    • CMA-ES (Covariance Matrix Adaptation Evolution Strategy) minimizes a function \(f\) from its values alone, so it needs no gradient
    • It keeps a normal distribution \(\mathcal{N}(m, \sigma^2 C)\). Every generation samples \(\lambda\) points from it, ranks them by \(f\), and moves the distribution toward the best ones
    • The mean \(m\) says where to search, the step size \(\sigma\) how far, and the covariance \(C\) in which shape

  • Example: the smallest circle
    • Find the smallest circle that holds six points. Search for its centre \((x, y)\), so there are two parameters (\(n = 2\))
    • Once the centre is fixed, the circle only has to reach the farthest point, so its radius is
      \[ f(x, y) = \max_i \, \lVert (x, y) - p_i \rVert \]
      A smaller \(f\) is a smaller circle

  • One generation as equations
    • The figure above runs these four updates:
      \[ \begin{aligned} x_k &= m + \sigma\, y_k, \quad y_k \sim \mathcal{N}(0, C) \\ m &\leftarrow \textstyle\sum_{i=1}^{\mu} w_i\, x_{i:\lambda} \\ C &\leftarrow (1 - c_1 - c_\mu)\, C + c_1\, p_c p_c^\top + c_\mu \textstyle\sum_{i=1}^{\mu} w_i\, y_{i:\lambda} y_{i:\lambda}^\top \\ \sigma &\leftarrow \sigma \exp\!\left( \tfrac{c_\sigma}{d_\sigma} \left( \tfrac{\| p_\sigma \|}{\mathbb{E} \| \mathcal{N}(0, I) \|} - 1 \right) \right) \end{aligned} \]
    • Here \(x_{i:\lambda}\) is the \(i\)-th best sample, \(y_{i:\lambda}\) its step from the old mean, and \(p_c, p_\sigma\) are decaying sums of recent mean steps. The rates \(c\) and weights \(w\) have defaults
    • In genetic-algorithm terms:

      Genetic algorithmCMA-ES
      Population size\(\lambda\) samples per generation, by default \(4 + \lfloor 3 \ln n \rfloor\) (6 in the figures)
      FitnessOnly the rank of \(f\), not its value
      Selected parentsThe best \(\mu = \lfloor \lambda / 2 \rfloor\) samples (3 in the figures)
      CrossoverThe weighted average of the parents, which becomes the new mean \(m\)
      MutationSampling from \(\mathcal{N}(m, \sigma^2 C)\), whose size \(\sigma\) and shape \(C\) are learned
      Kept between generationsOnly \(m\), \(\sigma\), and \(C\); the samples are dropped, not carried over

  • Many generations
    • Over many generations, \(C\) takes the shape of the contour lines, and \(\sigma\) follows whether recent steps agree

  • Why learn \(C\)
    • Learning \(C\) matters most when the contours are long and thin
    • With \(C\) fixed to a circle, \(\sigma\) must stay small enough for the narrow direction, so the search crawls along the long one

  • In practice
    • Only a start \(m_0\) and a step size \(\sigma_0\) are chosen; the rest has defaults, such as \(\lambda = 4 + \lfloor 3 \ln n \rfloor\). Memory grows as \(n^2\)
    • The Python package pycma runs the same loop: 
      
    import cma

    def f(x):
        return sum((i + 1) * xi**2 for i, xi in enumerate(x))

    es = cma.CMAEvolutionStrategy(x0=[1.0] * 10, sigma0=0.5)
    while not es.stop():
        X = es.ask()                   # sample lambda candidates
        es.tell(X, [f(x) for x in X])  # rank, update m, sigma, C
    print(es.result.xbest)
    • The figures run a JavaScript port of purecma.py from pycma, with positive weights only
