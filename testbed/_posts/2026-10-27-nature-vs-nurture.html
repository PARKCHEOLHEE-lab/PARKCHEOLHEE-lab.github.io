Introduction

This project uses the browser game 1 in 8 Billion to examine how birth conditions, talent, choices and random events affect a simulated life. The game follows a person from birth to death using public statistics from 172 countries. Running the same birth under different life plans keeps country, family and talent fixed while the assigned choices change. Claude (Opus-5.5) prepared the original simulation code and experiments. Codex (GPT-6.1-sol) ran a matched sample with new birth and policy seeds. Both fixed-plan samples have since been expanded from 1,000 to 5,000 births using the same code. These extensions were executed through Codex; no new Claude session was used. “Claude” and “Codex” identify the original seed samples. The figures compare samples from a shared simulator, not two independent game engines or the models’ coding ability.

Each sample contains 50,000 fixed-plan lives (5,000 births × 10 plans), 50,000 lifelong random-plan lives and 50,000 lives with choices drawn again at each decision. All ten fixed plans are included. Together the two samples contain 300,000 main-experiment lives. The outcome, “happy years”, combines lifespan with the game’s happiness score. A separate luck experiment repeats 200 births five times per sample and is outside that total.

The results describe the game’s model. Country selection is weighted by births, while mortality and income use country life tables and income distributions (About 1 in 8 Billion). Talent, yearly activities and decisions follow rules chosen by the author. Country life satisfaction and family income already enter the happiness formula, limiting what these results can say about real lives. North Korea, for example, has no survey happiness score in the game’s data, so the game uses 5 out of 10.

A related study is the “Talent vs Luck” model by Pluchino, Biondo and Rapisarda (2018). It follows 1,000 people with different talents through lucky and unlucky events over a 40-year working life. Here, the experiment uses an existing game based on public statistics and measures outcomes over a whole life.


The simulator

The game represents a life through yearly activities, decisions and events. Each year, the player selects a focus such as study, work, family, health or rest. Its 152 types of decisions cover school, employment, marriage, migration, gambling, medical care and other situations. The game tracks health, happiness, knowledge and relationships on a scale from 0 to 100, together with talent scores fixed at birth.

The game already runs complete lives without displaying them, using these functions to simulate the four other babies "born in the same second" as the player. Both matched batches use the game's companion mode, which omits some player-only events. The experiment runs those functions through an external program:
  • Playwright loads the game's code unchanged from a local server into Chromium without a visible browser window. Requests to outside hosts are blocked during the runs.
  • Auto mode handles decisions that the assigned plan does not specify.
  • A random seed fixes the birth, family and talent. Repeating the same seed and plan reproduces the same life.
  • For luck replays, a second seed resets the random events after birth while keeping the birth, family and talent fixed.
  • At each birthday, the program records happiness, health, knowledge, relationships and income. Each decision is also recorded with its available options and selected answer.
\[ \begin{array}{l} \textbf{Algorithm: } \text{Run one life} \end{array} \]
\[ \begin{array}{l} \textbf{Input: } \text{seed } s, \text{ plan } \pi, \text{ event seed } e \text{ (luck replays only)} \\ \textbf{Output: } \text{yearly records } (h_t, \text{health}, \text{knowledge}, \text{relationships}, \text{income}), \text{ happy years} \end{array} \]
\[ \begin{array}{l} \text{seed the game's random numbers with } s \text{; draw the birth (country, family, sex, talent)} \\ \textbf{if } e \text{ is given } \textbf{then } \text{seed the random numbers again with } (s, e) \\ \text{turn on auto mode} \\ \textbf{while } \text{alive } \textbf{do} \\ \quad \textbf{if } \text{a decision is pending } \textbf{then} \\ \qquad O \leftarrow \text{the options the game offers} \\ \qquad a \leftarrow \pi\text{'s option in } O \text{ if it has one, } \textbf{else } \text{the game's own choice} \\ \qquad \text{answer } a\text{; } \textbf{continue} \\ \quad \text{focus} \leftarrow \pi\text{'s first focus among this stage's options, } \textbf{else } \text{keep the game's own} \\ \quad \text{advance half a year} \\ \quad \textbf{if } \text{a birthday passed } \textbf{then } \text{record year } t \text{ and let } \pi \text{ pick the focus again} \\ \textbf{return } \text{happy years} = \sum_t h_t / 100 \end{array} \]
Fixed plans select the first available option in their ordered lists. Balanced selects the middle option, while the random-plan experiments use random choices.


The game's code belongs to its operator (Terms). The descriptions and notation here explain the rules needed to interpret the results, without reproducing the game's code.


Ten life plans

Each life plan specifies a focus for each life stage and preferred answers to selected decisions. Focus options are stored as ordered lists for each stage. The plan selects the first option the game offers; for example, a working child cannot select "study", so the plan tries its next option. The game-default plan uses auto mode for every choice and serves as the control group.

Measuring a life: happy years

The main outcome, happy years, combines the length of a life with the game's happiness score. Age at death, income, happiness and knowledge each describe only part of the outcome. Happy years is calculated by summing the happiness recorded at each birthday, divided by 100:
\[ \text{happy years} = \sum_{t=1}^{T} \frac{h_t}{100} \]
where \( h_t \) is the happiness score at birthday \( t \) and \( T \) is the age at death. For example, happiness scores of 60, 80 and 50 on the three birthdays of a child who dies at 3 produce 0.6 + 0.8 + 0.5 = 1.9 happy years. These are birthday observations rather than averages over each year. The calculation can be represented as the area under the happiness curve, with a fully happy year contributing 1.

The same calculation applies to every life, including those that end in early childhood.

Happiness is one of the game's four status scores, alongside health, knowledge and relationships. The game describes it as life satisfaction influenced by income, family and friends, health and debt. Each year, the score moves part of the way toward a target level. This target uses the country's average life satisfaction from the World Happiness Report 2024, the person's income rank (or family income group during childhood), relationships, health and heavy debt.

Events and decisions also change happiness between yearly updates. Illness, marriage, job loss and a successful hobby can move the score away from its target, while later updates gradually reduce that difference. The yearly focus makes an additional adjustment.

The game's code defines the yearly target \( T \) and happiness update \( h \) as follows:
\[ T = \underbrace{28 + 5.5\,W}_{\text{country}} + I + 0.25\,(R - 50) + 0.2\,(H - H_{\text{age}}) - D - 12\,s \] \[ h \leftarrow h + k\,(T - h) \]
Here, \( W \) is the country's World Happiness Report score, measured from 0 to 10 using survey data, and \( I \) is the income contribution. The variables \( R \) and \( H \) represent relationships and health, while \( H_{\text{age}} \) is the expected health at that age and \( D \) is the debt contribution. The adulthood adjustment \( s \) increases from 0 at age 14 to 1 at age 20. The update rate \( k \) determines how far happiness moves toward the target each year.

The other numbers are constants chosen by the game's author and used for every life:

Additional terms include +3 for a dream job, −10 for being a refugee and −4 to −7 during a mental-health struggle. The final happiness score is limited to the range from 0 to 100. For comparison, the country contribution alone is 70.6 in Finland (\( W = 7.74 \)) and 37.5 in Afghanistan (\( W = 1.72 \)).

This definition makes part of the measured relationship between birth, income and happiness a property of the game's rules. A country with higher life satisfaction or a family with a higher income rank gives the person a higher target. These terms therefore contribute to both the estimated birth effect and the relationship between income and happy years.

The analysis also reports lifetime income, calculated as the sum of yearly income in PPP dollars, and age at death. Knowledge is excluded because the study focus increases it directly by design. Comparing knowledge across plans would therefore largely restate that rule, as in a finding that Scholar produces the highest knowledge score.


Experiment design

  • Fixed plans: 5,000 births × 10 plans = 50,000 lives per sample. Every birth uses all ten plans, allowing paired comparisons.
  • Lifelong random plans: 50,000 new births per sample, each assigned lasting preferences for focus options and answers.
  • Random decisions: 50,000 other births per sample, with a new answer at each decision and a new focus each year.
  • Luck experiment (separate): the first 200 births, each run five times under the game default with different event seeds, giving 1,000 futures per sample.
The main total is 150,000 lives per sample and 300,000 across both samples. It includes every fixed plan. These are 105,000 distinct births per sample because 5,000 births each appear under ten plans. The separate luck experiment and illustrative examples are excluded from the main total.

With 5,000 lives per plan, the approximate 95% margin for a proportion near 50% is ±1.4 percentage points, using \(1.96\sqrt{p(1-p)/N}\). Plans are compared with the game default on the same birth seeds. The Holm correction covers the nine plan comparisons. Contributions to variation use the linear model happy years ~ birth (country, family income fifth, sex) + six talent scores + plan. LMG divides the fitted \(R^2\) between these groups; the remaining variation stays unexplained.

Individual-choice regressions use robust HC1 errors and control for the offered options, region, family income fifth, sex and talent. Benjamini-Hochberg controls the expected share of false findings among selected results at 5%. When an income, life-path or sex comparison includes several paths from the same birth, its interval keeps those paths together. The talent bootstrap also resamples whole births.

The original 220,000 main-experiment lives were retained, with 40,000 fixed-plan lives added to each sample. All birthday totals matched the raw records; there were no failed additions or outside requests, and the old inputs were unchanged. India represents 17.1% of the 5,000 fixed-plan births in the Claude sample and 18.3% in the Codex sample, against the game’s 17.6% weight. Unless a Codex value is named, the text and plan table use the expanded Claude sample.

Each sample contains five girls and five boys. To reach this balance, the selection replaces the fewest examples. Replacements use the other sex and stay nearest the same country’s median; countries needing the smallest added distance change first.

Each selected birth then follows 200 futures with different events after birth. These illustrative futures are outside the 300,000-life main total. Family, sex and talent differ between the selected babies as well as country. Their differences cannot be attributed to country alone.


Sex at birth

Across all 150,000 main-experiment paths per sample, females live 1.92 years longer on average in the Claude sample and 2.55 years longer in the Codex sample. The happy-year gaps are smaller: 0.22 and 0.76, respectively. The Claude happy-year interval includes zero (-0.07 to 0.50), so that sample does not establish a clear female advantage in the underlying mean. These comparisons describe female and male groups under the experiment’s mix of plans. They do not change only sex at birth while holding every other condition fixed.


Which single choices matter

The ten fixed plans combine many choices, so they cannot separate the effects of the game's 152 decision types. The two random-plan experiments vary individual answers to estimate these effects. Random answers allow comparisons between choices, but the available options also depend on a person's situation. These differences must be accounted for before estimating an answer's effect.

For example, "sell a rented-out house" is offered only to people who own one, in 0.74% of lives that fall into debt in the Claude sample. Comparing everyone who sells one with everyone who asks family for help gives an apparent gain of 12.3 happy years. However, the first group was already wealthier before the decision. Restricting the comparison to lives offered both answers reduces the estimate to +0.6 (95% CI −2.5 to +3.7).
Each answer is compared with the most common answer among lives whose first occurrence of that decision offered both options. The matched Codex rerun keeps Claude's comparison answer for the decision types in the six comparisons above and for smoking. Other decision types use the most common answer in their own sample. The regression controls for the offered options, region, family income group, sex and the six talent scores. The initial analysis omitted this control. Most of its largest estimates reflected differences in the available options.

In the Claude analysis, 64 of 283 comparisons pass the significance threshold after this adjustment in the lifelong-plan experiment and 52 of 272 in the per-decision experiment. Decisions occurring in fewer than 200 lives are excluded: 24 decision types in the first experiment and 22 in the second.

In the lifelong-plan experiment, the same answer is used whenever a decision recurs. The following estimates describe the Claude sample. The largest estimated effects concern health and employment. Hiding HIV and never starting treatment reduces happy years by 12.1. Repeatedly waiting for a better job, which means never accepting an offered job, reduces the outcome by about 11, while delaying TB treatment reduces it by 6.5.

An adult work focus produces 4.5 fewer happy years than a balance focus, consistent with the results for the three work-based plans. Accepting marriage adds 4.5 happy years.
The per-decision experiment measures the first answer while later answers are drawn again at random. Its estimated effects are smaller because later choices can reverse an earlier decision. In the Claude sample, hiding HIV at the first decision reduces happy years by 3.3, compared with 12.1 when repeated throughout life. The largest individual effects include staying home instead of accepting a job (−4.7), receiving TB treatment (+4.4), reducing drinking (+3.3) and refusing the first cigarette (+2.8).


Life paths

Education and marital status provide another way to group completed lives. Among adult paths under fixed plans in the Claude sample, 16.5% never attend school and 23.6% finish university. Their mean happy years differ by 13.2, from 39.0 to 52.1. These are descriptions of completed lives, not isolated effects of education or marriage. A path also depends on how long the person lives. Being widowed at death (39.4% of adult paths and 51.4 happy years) largely reflects a long life, while early death leaves less time to marry.


What counts as luck

Talent can also be treated as part of birth conditions because the game assigns it at birth, together with country and family. Under this grouping in Claude's run, birth conditions account for 29.2% of variation (birth 27.8% + talent 1.4%), events after birth for about two thirds and the life plan for 5.3%.

The interpretation of effort is less direct. Rawls argued that "even the willingness to make an effort, to try, and so to be deserving in the ordinary sense is itself dependent upon happy family and social circumstances" (A Theory of Justice, 1971, §17). In the game, the player selects a temperament at age two, including an option to continue trying after failure.

The game also notes a genetic contribution to temperament. A meta-analysis of behavior genetic studies estimates that genes account for about 40% of differences in personality (Vukasović and Bratko, 2015).

This experiment measures how outcomes change when the same baby follows a different assigned plan. It does not resolve whether the willingness to make an effort is itself a form of luck. The plan’s 5.3% contribution describes the effect of choices under this design and does not establish who deserves a particular outcome. Available choices also depend on the person's situation, as the decision comparisons demonstrate.


Earlier independent Codex study

The paired figures above use shared simulation and analysis code. An earlier Codex study used separately written code and a different experiment design. It is kept separate from the expanded main experiments. The figure below preserves the original 1,000-birth Claude snapshot for this historical comparison. OpenAI's Codex (GPT-6.1-sol) received the same game version (0.8.54 beta) and research question for an independent comparison. It had no access to this article, the analysis code or the results.

Codex designed a separate experiment with 2,000 births, each replayed with 3 different futures under 8 focus combinations. These combine childhood study or play with adult balance, work, health or family. It also tested six individual decisions on 1,500 new births, producing 58,636 lives in total. Codex accumulates happiness continuously between events, while Claude records it at birthdays.


Two details affect how the intervals are read: Claude's birth contribution has no interval, and Codex's cigarette interval accounts for all six decision tests together. The talent measures also differ. Claude uses LMG to divide variation, while Codex measures how much the six talent scores improve predictions for births excluded from model fitting.

The work and health comparisons use different plans. Claude compares Hard worker and Health first with the game default; Codex compares work and health focuses with balance. These rows can therefore be compared by direction rather than by the size of the estimate.

Where the measures are comparable, the estimates agree within their 95% intervals. Codex also finds that work focus increases income while reducing happy years, consistent with the main experiment.


Limitations

  1. The measurements apply to the game's model. Talent, focus and decision effects follow rules chosen by its author, as does the happiness score. Country life satisfaction and income rank already enter the score's target, contributing to the measured birth and income relationships.
  2. Claude's luck estimate uses 200 births under the game default. Other plans or larger samples could produce values within or beyond its 95% interval of 59.6% to 73.4%. The independent experiment using 2,000 births under study and balance found 69.1%.
  3. The fixed-plan birth estimate uses 5,000 distinct births. Its 50,000 paths repeat each birth under ten plans. The birth group combines country, family income and sex; it is not an estimate of genetic inheritance.
  4. Each baby's plan ranking uses one set of random events per plan. Replaying the birth could change the ranking.
  5. Choice effects are estimated from the first occurrence of each decision. Rarely available answers have small comparison groups and wide intervals.
  6. Income groups and life paths describe completed lives. Their differences combine birth conditions, random events and choices, so they do not isolate causal effects.
  7. In the initial run, five plans specified focus options unavailable at the relevant stage, leaving 34% to 100% of their steps on auto focus. The lists were corrected and the 10,000 lives rerun. The expansion uses those same corrected lists; no game rule was changed.


Future work

  1. Replay each birth several times under every plan to estimate whether its plan ranking persists across different random events.
  2. Estimate the contribution of events after birth under additional plans and with more births.
  3. Repeat the analysis within individual countries to measure the contribution of plans when country is held fixed.
