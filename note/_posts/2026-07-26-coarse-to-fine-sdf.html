--- title: "Coarse-to-Fine SDF" layout: post related: - deep-sdf - latent-shapes-experiment - linear-interpolation - voxels-to-graph ---
  • A dense grid is mostly waste
    • A signed distance function (SDF) answers one question per point. How far away is the surface? And is the point inside or outside? Inside gives a minus value, outside a plus. The shape is where the answer is zero. Every figure below draws inside points red and outside points blue

    • To build a mesh, sample the function on an \(R \times R \times R\) grid. Then marching cubes walks every cell. It is the standard way to read a surface off a grid. Where the corner signs differ, it draws triangles
    • A sign change means two corners \(p_0\) and \(p_1\) sit on opposite sides. So the surface must cross the edge between them. But where on that edge? Write a point on it as \(p(t) = p_0 + t(p_1 - p_0)\). Let the value change in a straight line, \(v(t) = v_0 + t(v_1 - v_0)\). Then ask where it reaches zero:
      \[ 0 = v_0 + t(v_1 - v_0) \quad \Longrightarrow \quad t = \frac{v_0}{v_0 - v_1} \]
      One \(t\) does two jobs. The two values give it, and the position uses it: \(p_0 + t(p_1 - p_0)\). So the point lands nearer the corner whose value is closer to zero. It does not sit at the middle

    • The grid decides the cost. \(R = 128\) means 2,097,152 queries. Doubling \(R\) multiplies that by eight. Often the SDF is a small neural network, called a decoder. Then those queries are nearly the whole cost
    • A surface is 2D inside a 3D grid. Cost grows like \(R^3\). But the answer only lives on \(R^2\) cells. So almost every query reports empty space

  • Refine only near the surface
    • Start on a cheap grid. At each finer level, evaluate only the cells the surface could pass through. Halve \(R = 128\) until it reaches a floor of 16. That gives the ladder \(16 \rightarrow 32 \rightarrow 64 \rightarrow 128\). Only the coarsest level samples everything. \(16^3\) is just 4,096 points, about 0.2% of the dense grid
    • A cell is kept when its corner signs differ. It is also kept when any corner lies within \(\tau h\) of the surface. Here \(h\) is the cell size. So some kept cells hold no surface at all, and that is on purpose. The band saves thin parts: a part thinner than one cell can leave all eight corners outside. And a cell dropped once never comes back
    • Every level ends with marching cubes, so each one produces a complete mesh. The loop repeats until it reaches the finest level
    • It behaves like an octree, but the code does not store one. An octree splits space into eight parts, again and again. Here each level still builds a full uniform grid. Only the decoder calls are cut. Unmarked points copy the coarse value. Marching cubes wants a regular grid anyway, and the decoder is where the cost is
    • The figure below runs the ladder \(4 \rightarrow 64\) cells per axis. Its band is narrow, \(\tau = 0.5\), so the picture stays clear. It samples 42,034 points. Sampling every point would need 274,625. And the mesh that comes out is identical to the dense one, vertex for vertex. It has 14,706 triangles. A real run keeps a wider band, around \(\tau = 2.5\). It then grows the mask by one more cell
